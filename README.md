# EventManager — приложение для организации мероприятий

Проект создан по кейсу №215 «Event manager на Python» в рамках кейс-фестиваля «Будущее Петербурга — в творчестве юных».

Ссылка на кейс (стр.9 , название "Event manager на Python" №215) : https://radar-mms.com/upload/medialibrary/d21/znig5cr12btj6ud16xeimfugc2akr1n2.pdf

## Описание
Приложение помогает организатору вести списки гостей и участников, управлять ролями, а также планировать бюджет мероприятия.


## Технологии
* **Язык:** Python 3.13
* **Интерфейс:** Tkinter / CustomTkinter
* **Данные:** CSV-файлы
* **Почта:** SMTP (Яндекс.Почта)

## Как запустить
1. Скачайте репозиторий.
2. Установите зависимости: `pip install customtkinter python-docx`
3. Создайте в корневой папке файл `settings.json` с вашими данными:
   ```json
   {
       "email": "ваш_логин@yandex.ru",
       "app_password": "ваш_пароль_приложения"
   }
4. Запуск осуществляется с `Main_window.py`
